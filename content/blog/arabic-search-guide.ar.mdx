# البحث العربي: لماذا يفشل وكيف تصلحه

يفشل البحث العربي لأن الكلمة الواحدة تُكتب بأكثر من صورة — `أحمد` أو `احمد`، و`مدرسة` أو `مدرسه`، مشكولةً أو بلا تشكيل — ومحرك البحث المضبوط للإنجليزية يعاملها كنصوص مختلفة. والحل توحيد النص المفهرس وكل استعلام: صور الألف إلى `ا`، والتاء المربوطة إلى `ه`، والألف المقصورة إلى `ي`، وحذف التشكيل والتطويل، ثم تطبيق مجذّع عربي خفيف لتطابق `الكتاب` كلمة `كتاب`. ومحركات مثل Elasticsearch تفعل ذلك جاهزاً بمجرد اختيار محللها العربي.

البلاغ المعتاد: مستخدم يبحث في كتالوجك العربي عن منتج موجود فعلاً فلا يجد شيئاً، والفريق يشك في طبقة الاستعلام. والسبب في الغالب هو النص نفسه. يغطي هذا الدليل ما يُوحَّد وكيف؛ وبحث بهذه الجودة جزء من المشاريع العربية في [خدمات تطوير الويب](/ar/services/web-development) لدينا. وللنطاق الأوسع راجع [الدليل الكامل لتعريب التطبيقات والمواقع](/ar/blog/arabic-localization-guide).

## لماذا تفشل المطابقة الحرفية

أربع خصائص في الكتابة العربية تكسر البحث الساذج.

**1. صور الألف.** للألف عدة صور — `ا` و`أ` و`إ` و`آ` — والكُتّاب لا يلتزمون بها. البحث عن `احمد` لن يطابق `أحمد` دون توحيد، وهذا من أشيع أسباب غياب النتائج.

**2. التاء المربوطة والهاء.** كثيراً ما تُكتب `ة` في آخر الكلمة `ه`. فـ`مدرسة` و`مدرسه` كلمة واحدة للقارئ ونصّان مختلفان لقاعدة البيانات.

**3. التشكيل.** الحركات كالفتحة والضمة اختيارية. المحتوى المُدخل مشكولاً لن يطابق استعلاماً بلا تشكيل، والمستخدمون نادراً ما يكتبونه.

**4. الألف المقصورة والياء.** كثيرون يكتبون `ى` و`ي` في آخر الكلمة بالتبادل — `على` و`علي`.

**والأرقام حالة خامسة.** استعلام مكتوب بأرقام عربية مشرقية (`١٥`) لن يطابق `15` في الكتالوج، ولوحات المفاتيح الفارسية والأردية تُنتج مجموعة أرقام ثالثة (`۱۵`).

**النتيجة:** الكلمة العربية الواحدة قد تُكتب بأربع صور أو أكثر تبدو كلها صحيحة للقارئ، والمطابقة الحرفية تجد واحدة منها فقط.

## التوحيد: الحل الأساسي

التوحيد يعني تحويل النص إلى صورة قياسية قبل المقارنة. طبّقه على المحتوى المفهرس وعلى الاستعلام الوارد معاً — توحيد طرف واحد لا يحقق شيئاً.

**مجموعة تحويلات عاملة في JavaScript:**

```js
function normalizeArabic(text) {
  return text
    .normalize("NFC")
    // الحركات (U+064B–U+065F) والألف الخنجرية (U+0670)
    .replace(/[\u064B-\u065F\u0670]/g, "")
    // التطويل (الكشيدة)
    .replace(/\u0640/g, "")
    // الألف المهموزة والممدودة ← ألف مجردة
    .replace(/[\u0622\u0623\u0625\u0671]/g, "\u0627")
    // التاء المربوطة ← هاء
    .replace(/\u0629/g, "\u0647")
    // الألف المقصورة ← ياء
    .replace(/\u0649/g, "\u064A")
    // الهمزة على الواو والياء (اختياري؛ مُوحِّد Lucene لا يغيّرهما)
    .replace(/\u0624/g, "\u0648")
    .replace(/\u0626/g, "\u064A")
    // الأرقام العربية المشرقية والفارسية ← أرقام غربية
    .replace(/[\u0660-\u0669]/g, (d) => String(d.charCodeAt(0) - 0x0660))
    .replace(/[\u06F0-\u06F9]/g, (d) => String(d.charCodeAt(0) - 0x06F0))
    .toLowerCase()
    .trim();
}

normalizeArabic("أَحْمَد");     // "احمد"
normalizeArabic("آيفون ١٥");   // "ايفون 15"
```

**اكتب النطاقات بأرقام المحارف لا بمحارف ملصوقة.** نطاق تشكيل مكتوب بلصق حركتين يسهل الخطأ فيه: النطاق الممتد حتى U+0670 يبتلع معه الأرقام العربية المشرقية U+0660–U+0669، فيحذف كل رقم في النص دون أن ينتبه أحد.

**خزّن الصورة الموحّدة بجوار الأصل.** اعرض الأصل للمستخدم — فالنص الموحّد يبدو غريباً قليلاً — وابحث في العمود الموحّد.

**ولا توحّد مصدر الحقيقة.** الأسماء والنصوص القانونية والدينية قد تحتاج صورها الدقيقة. التوحيد لفهرس البحث فقط.

## دع محرك البحث يتولى الأمر

التوحيد اليدوي يكفي للحالات البسيطة، لكن محركات البحث الناضجة تأتي بتحليل عربي جاهز يشمل التجذير، وهو ما لا تُحسنه التعبيرات النمطية.

**Elasticsearch / OpenSearch.** المحلل المدمج `arabic` أبسط بداية. و[مكافئه الموثّق](https://www.elastic.co/guide/en/elasticsearch/reference/current/analysis-lang-analyzer.html) يُظهر السلسلة التي يمكنك إعادة بنائها للتخصيص:

```json
{
  "settings": {
    "analysis": {
      "filter": {
        "arabic_stop": { "type": "stop", "stopwords": "_arabic_" },
        "arabic_stemmer": { "type": "stemmer", "language": "arabic" }
      },
      "analyzer": {
        "rebuilt_arabic": {
          "tokenizer": "standard",
          "filter": [
            "lowercase",
            "decimal_digit",
            "arabic_stop",
            "arabic_normalization",
            "arabic_stemmer"
          ]
        }
      }
    }
  }
}
```

- `decimal_digit` يحوّل مجموعات الأرقام الأخرى، ومنها العربية المشرقية، إلى `0–9`.
- `arabic_normalization` يطبّق [ArabicNormalizer](https://lucene.apache.org/core/9_0_0/analysis/common/org/apache/lucene/analysis/ar/ArabicNormalizer.html) من Lucene: الألف المهموزة إلى ألف مجردة، والتاء المربوطة إلى هاء، والألف المقصورة إلى ياء، وحذف الحركات والتطويل.
- المجذّع العربي يطبّق [ArabicStemmer](https://lucene.apache.org/core/9_0_0/analysis/common/org/apache/lucene/analysis/ar/ArabicStemmer.html) من Lucene، الذي يزيل «ال» التعريف وحروف العطف والجر المتصلة ويحذف اللواحق الشائعة. وهذا **تجذير خفيف لا استخراج للجذر**: تطابق `الكتاب` و`وبالكتاب` كلمة `كتاب`، أما جمع التكسير `كتب` فلا.

**PostgreSQL.** يتضمن كود PostgreSQL مجذّعاً عربياً من Snowball، فالبحث النصي الكامل بإعداد عربي متاح، وأفضل بكثير من `LIKE '%term%'` في الدقة والسرعة. أما التشكيل فيحتاج عناية: يصف التوثيق قواعد [`unaccent`](https://www.postgresql.org/docs/current/unaccent.html) الافتراضية بأنها موجهة للحركات الأوروبية، فوفّر ملف قواعد مخصصاً يحذف الحركات العربية، أو وحّد النص في كود التطبيق قبل الفهرسة.

**خدمات البحث المُدارة** (Algolia وTypesense وMeilisearch وغيرها) توفّر عليك تشغيل خوادم البحث. راجع توثيق كل منها للعربية بشأن التوحيد والتجذير، وشغّل عليها مجموعة الاختبار أدناه قبل الالتزام.

## التجذير و«ال» التعريف

العربية غنية صرفياً — السوابق واللواحق تتصل بالكلمة مباشرة، وهذا يُفشل البحث بالنص الجزئي.

**«ال» التعريف أشيع الحالات.** يجب أن تتطابق `الكتاب` و`كتاب`. المجذّع يتولى ذلك؛ والمطابقة الساذجة لا.

**السوابق تتراكم:** `وبالكتاب` تحوي حرف العطف `و` وحرف الجر `ب` و«ال» والاسم. القارئ يفككها فوراً؛ والبحث بالنص الجزئي لا.

**استخدم محللاً بدل كتابة قواعد حذف السوابق.** القواعد اليدوية تحذف أكثر من اللازم — إزالة `ال` من كلمة تبدأ بهذين الحرفين أصلاً تُنتج مطابقات خاطئة، والخطأ صامت.

**واعرف حدود التجذير الخفيف.** الجموع التي تغيّر بنية الكلمة الداخلية (`كتاب` ← `كتب`، `مدينة` ← `مدن`) لا يلتقطها حذف السوابق واللواحق. إن كانت مهمة لكتالوجك، فأضف مرادفات لمصطلحاتك الأساسية بدل مجذّع جذري متشدد يدمج كلمات لا علاقة بينها.

## الاستعلامات المختلطة عربي/إنجليزي

المستخدمون يخلطون اللغتين بحرية، خصوصاً في المصطلحات التقنية وأسماء العلامات. قد يكون الاستعلام: `افضل laptop للبرمجة`.

**فهرس اللغتين في الحقل نفسه.** فصل العربية والإنجليزية في حقلين يعني أن الاستعلام المختلط لا يطابق أياً منهما جيداً.

**أضف أسماء بديلة بالحرفين.** المستخدمون يبحثون عن `آيفون` و`iPhone` بالتبادل. إن خزّن كتالوجك صيغة واحدة، فالأخرى لا تُرجع شيئاً. خزّن الصيغتين لأسماء العلامات والمنتجات.

**وأبقِ تحويل الأحرف الصغيرة في السلسلة.** لا يغيّر شيئاً في الحروف العربية، لكنه ضروري للنص اللاتيني المضمّن.

## الترتيب والصلة

الحصول على المطابقات نصف المهمة؛ وترتيبها بشكل معقول النصف الآخر.

**المطابقة الحرفية تتقدم على المطابقة المجذّرة.** من يكتب اسم منتج بدقة يتوقعه أولاً. فهرس حقلاً فرعياً بلا تجذير وارفع وزنه.

**وزّع الأوزان على الحقول.** التطابق في العنوان أهم منه في الوصف.

**عالج النتيجة الفارغة.** أخطاء الكتابة على لوحة المفاتيح العربية تختلف عن الإنجليزية. المطابقة التقريبية بمسافة تحرير صغيرة، مع اقتراح «هل تقصد»، تحوّل الطريق المسدود إلى نتائج.

**سجّل الاستعلامات التي لا تُرجع شيئاً.** هذا أنفع تشخيص للبحث يمكنك إضافته: استعلامات النتائج الصفرية تكشف تحديداً حالة التوحيد الناقصة، والمحتوى الذي يتوقعه المستخدمون ولا تملكه.

## الاختبار

ابنِ مجموعة اختبار من لغة المستخدمين الفعلية لا من كتابتك أنت:

- الكلمة نفسها مشكولة وغير مشكولة
- كل صورة من صور الألف لمصطلح شائع
- نهايات `ة` و`ه`
- مع «ال» التعريف وبدونها ومع السوابق المتراكمة
- أرقام عربية مشرقية وغربية في الاستعلام نفسه
- عربي وإنجليزي في استعلام واحد
- الأخطاء الإملائية الشائعة من سجل النتائج الصفرية

**أتمت هذه كاختبارات تراجع.** إعدادات البحث سهلة الكسر أثناء ترحيل الفهرس، والكسر صامت — لا خطأ يظهر، فقط نتائج أسوأ.

## الأسئلة الشائعة

### لماذا لا يجد البحث العربي منتجات موجودة في الكتالوج؟

غالباً بسبب غياب التوحيد. الاستعلام والنص المخزّن يستخدمان صورتين مختلفتين للكلمة نفسها — `أ` مقابل `ا`، أو `ة` مقابل `ه`، أو تشكيل مقابل لا تشكيل، أو أرقام مشرقية مقابل غربية. وحّد الفهرس والاستعلام معاً وستظهر معظم المنتجات «المفقودة».

### أي المحارف يجب أن يغيّرها مُوحِّد النص العربي؟

كحد أدنى: الألف المهموزة والممدودة (`أ إ آ`) إلى `ا`، و`ة` إلى `ه`، و`ى` إلى `ي`، وحذف الحركات (U+064B–U+065F وU+0670) والتطويل (U+0640). وهذا تحديداً ما يفعله مُوحِّد Lucene العربي. وتحويل الأرقام العربية المشرقية إلى غربية إضافة معقولة.

### هل يردّ المجذّع العربي في Elasticsearch الكلمات إلى جذرها؟

لا. هو مجذّع خفيف: يزيل السوابق المتصلة مثل `و` و`ب` و`ال` ويحذف اللواحق الشائعة، فتطابق `الكتاب` كلمة `كتاب`. أما جموع التكسير مثل `كتب` فلا يطابقها. استخدم المرادفات للمصطلحات الأساسية حيث يهم ذلك.

### مُوحِّد النص لديّ يحذف الأرقام العربية المشرقية. لماذا؟

لأن نطاق التشكيل فيه يمتد على الأرجح من U+064B إلى U+0670، وهذا يشمل الأرقام العربية المشرقية U+0660–U+0669. استخدم `[\u064B-\u065F\u0670]` بدلاً منه، وحوّل الأرقام صراحةً بدل حذفها.

### كيف أدعم الاستعلامات المختلطة عربي/إنجليزي؟

فهرس اللغتين في الحقل نفسه، وأبقِ تحويل الأحرف الصغيرة في السلسلة للجزء اللاتيني، وخزّن أسماء بديلة بالحرفين لأسماء العلامات والمنتجات لتطابق `آيفون` و`iPhone` معاً.

### هل يكفي البحث النصي في PostgreSQL للعربية؟

للكتالوجات المتوسطة غالباً نعم: يتضمن مجذّعاً عربياً من Snowball ويتفوق على `LIKE '%term%'` في الصلة والسرعة. لكن خطّط للتشكيل بنفسك، لأن قواعد `unaccent` الافتراضية مصممة للحركات الأوروبية. والكتالوجات الكبيرة أو التي يعتمد عملها على البحث تستفيد من ضبط الصلة في محرك متخصص.

### ما أنفع إضافة واحدة للبحث العربي؟

سجل بالاستعلامات التي تُرجع صفر نتائج. يكشف حالات التوحيد الناقصة والمحتوى الذي يتوقعه المستخدمون، ولا يتطلب أكثر من أسطر قليلة من الكود.

## الخطوة التالية

وحّد الطرفين، واستخدم المحلل العربي في محرك البحث بدل قواعد حذف السوابق اليدوية، واعرف أين يتوقف التجذير الخفيف، وسجّل استعلامات النتائج الصفرية. هذا التسلسل يعالج معظم شكاوى البحث العربي.

وإن كان بحثك يُفوّت نتائج الآن وتريد معرفة الخطوة الناقصة، [شاركنا بعض الاستعلامات التي تفشل](/ar/contact) ونشخّصها لك.
