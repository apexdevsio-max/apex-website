Paths are relative to `public/`, so `/images/blog/<slug>/hero-banner.jpeg` lives at
`public/images/blog/<slug>/hero-banner.jpeg` and is referenced in MDX exactly as the path column shows.

## Conventions

- **Format** `.jpeg`, **1280×720** (16:9) — matches every existing blog image.
- **Weight** 60–180 KB each, in line with the current set.
- **Both locales share one file.** The `.en` and `.ar` articles reference the same path, so any
  text baked into an image should be English, as in the existing images.
- **One folder per article**, named for the slug.
